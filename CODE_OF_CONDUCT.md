# Contributor Covenant Code of Conduct

We pledge to make participation in QuellOps welcoming and free from harassment.
Contributors must communicate respectfully, accept constructive feedback, and avoid
personal attacks, discrimination, sexualized conduct, threats, or publishing private
information.

Report conduct concerns privately to the project maintainers. Maintainers may edit or
remove contributions and temporarily or permanently restrict participation when this
code is violated. Enforcement decisions will consider context, impact, and whether a
participant takes responsibility and corrects the behavior.

This policy is adapted from Contributor Covenant 2.1.
