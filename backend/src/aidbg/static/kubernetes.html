Connect the first cluster

The agent makes an outbound connection. No kubeconfig is uploaded to aidbg.

Make aidbg reachable

Install the read-only agent

Run from this repository with the correct backend URL.

./scripts/install_k8s_agent.sh --backend-url https://aidbg.example.com --cluster production
3

Choose allowed namespaces

The cluster appears here automatically. Monitoring remains off until you select namespaces.
